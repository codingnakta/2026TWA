# 우리의 TWA

2026 일본 글로벌 방과후 · 팀별 Team Working Agreement 사이트.
팀이 스스로 정한 약속을 올리고, 해보고 나서 고친 변화 과정까지 기록합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 화면 + 기본 데이터 (사이트 제목·소개·공지) |
| `app.js` | 편집·버전·서명·번역 표시 등 동작 |
| `fonts/` | 케리스 케듀체, EF 다이어리체, Pretendard (웹용) |
| `netlify/functions/twa.mjs` | 저장 서버. 비밀번호 확인, 팀별 권한, 일본어 자동 번역 |
| `netlify.toml`, `package.json` | Netlify 설정 |

## Netlify에 올리기

1. Netlify에서 **Add new site → Import an existing project → GitHub**로 이 저장소를 고릅니다. 빌드 설정은 그대로 두면 됩니다 (`netlify.toml`이 처리).
2. 사이트를 열고 **편집 → 선생님 비밀번호**로 들어가서 공지사항을 쓰고 팀을 추가한 뒤 저장합니다. 첫 저장이 서버에 데이터를 만듭니다.
3. 각 팀 페이지의 편집 화면에서 **팀 비밀번호**를 정해 주면, 학생은 그 비밀번호로 자기 팀만 편집할 수 있습니다. 팀 비밀번호는 선생님만 보고 바꿀 수 있습니다.

선생님 비밀번호(`TEACHER_PASSWORD`, 기본값 `teacher`)와 DeepL API 키(`DEEPL_API_KEY`)는 `netlify/functions/twa.mjs` 상단에 하드코딩되어 있습니다. 바꾸려면 그 값을 고치고 다시 배포하면 됩니다. 환경변수는 따로 필요 없습니다.

서버가 없는 곳(로컬 파일, 다른 정적 호스팅)에서 열면 자동으로 **데모 모드**가 됩니다. 편집은 되지만 새로고침하면 사라집니다. 데모 비밀번호는 `index.html` 상단 `TWA_CONFIG`에 있습니다.

## 권한

| 역할 | 할 수 있는 것 |
|---|---|
| 선생님 | 모든 팀 편집, 팀 추가·삭제, 대문(Welcome) 제목·소개글, 공지사항, 전체 소통 채널, 팀 비밀번호 설정 |
| 팀 | 자기 팀 내용·팀원·서명 편집, 새 버전으로 저장 |
| 방문자 | 보기만 |

## 데이터

데이터는 Netlify Blobs(`twa` 스토어)에 JSON으로 저장됩니다. 편집 모드의 **JSON 복사**로 언제든 백업할 수 있습니다.
